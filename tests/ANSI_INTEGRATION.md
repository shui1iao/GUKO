# ANSI execution/report handoff — v0.7.3

- Stream accepts the `guko-unified-v1` machine execution envelope (required nonempty report object and original terminal string), exit 0 or complete exit 1. Business schema, catalogues, countries, verdicts, titles, order and colour/layout are upstream-owned; no local report reconstruction or Unknown count. Duplicate/nonfinite JSON, invalid UTF8, unknown envelope versions, empty/truncated/oversized data or unsafe terminal controls fail clearly. SGR/text are permitted. Exact terminal and raw JSON are archived, safely rendered and replayed without remeasurement.
- IPQuality keeps official `-y`/`-4` modes and same-invocation ANSI/official report links. Known title/footer extraction enables the existing image; unknown layout is an optional display failure, not a source rejection. Full original output is preserved/relayed even when extraction or rendering fails.
- NodeQuality keeps selected menu components, IPv4/dual-stack and official `-d` in a task-owned 0700 directory. It runs the exact hash-verified script, without sed-patching upstream cleanup or ping implementation. Existing retained logs can be read from that task's allowlisted path; if removed by upstream, original subreports are best-effort sliced from this invocation's tee stdout. Known current layout still produces partial-selection PNGs; unfamiliar titles/URLs fall back to the complete original output plus any recognized original links. Never scan old workdirs or re-upload reports.
- Full NQ retains its original combined link. Optional extraction/PNG failures are distinct from script exit; raw output is saved with history and escaped, fully chunked fallback (no three-chunk truncation). Old media/history/source offers are not relabelled.
- Renderer font/style/dependencies, 2MiB input bound, semaphore, CSP/resource/geometry/PNG safeguards and process-group timeout/cancellation reaping remain unchanged. Private font/golden tests stay conditional and are not redistributed.

Tests: `test_stream_unified`, `test_executor_decouple`, `test_ansi_integration`, `test_tool_sources`, `test_unified_cleanup`, original Kat/Snell/history/source/security suites, and `node --test telegram-bot/tests/test_render_ansi*.js`. All execution uses local HTTPmock/loopback/sentinels, not real platform requests, TG messages, benchmarks or installation. Skips and architecture scope are disclosed in the final delivery. Historical upstream attribution and licence notices remain in NOTICE-STREAM.md.
